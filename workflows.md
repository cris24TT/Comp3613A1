# Student Application for internship workflows 

## Workflow 1: Apply for internship(student)
1. Student logs into the application portal with credentials. 
2. Navigate to avaailable internship page.
3. Selects a desired internship and clicks Apply.
4. Uploads resume and fills out application form
5. Submits the application.
6. System confirms submission and generates an application ID.

## Workflow 2: Review Internship Application (Coordinator)
1. Coordinator logs into the system with admin credentials.
2. Opens the Applications Dashboard.
3. Selects an application to review.
4. Reads submitted details (resume, skills, availability).
5. Marks application as Accepted, Rejected, or Pending Review.
6. System updates the application status and notifies the student.

## Workflow 3: Track Internship Status (Student)
1. Student logs into the system.
2. Navigates to My Applications.
3. Selects the internship they applied for.
4. Views current status (e.g., Pending, Accepted, Rejected).
5. If accepted, sees next steps (e.g., onboarding instructions).
